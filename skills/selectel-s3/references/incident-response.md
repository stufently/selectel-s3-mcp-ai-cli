# Инцидент

Начни с `doctor`, конфигурации, head/list и аудита. При 429 учитывай лимиты запросов на бакет; SDK повторяет 429/503 с адаптивной задержкой. Часы важны для SigV4: документация указывает 15 минут срока подписи запроса. Не меняй скоуп или политику подтверждения для обхода отказа. При нулевом балансе доступ блокируется; через 30 дней Selectel удаляет данные, в том числе под Object Lock. Проверку баланса и управление ключами выполняет владелец через свои средства.
