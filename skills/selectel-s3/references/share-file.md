# Обмен файлом

`s3_presign_get` выдаёт ссылку для конкретного разрешённого ключа; по умолчанию 3600 секунд. Максимум 604800 секунд в профиле — предположение, не проверенный лимит Selectel. Передавай ссылку адресату и не записывай её подпись в журналы. Одноразовые ссылки создаются в панели. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
