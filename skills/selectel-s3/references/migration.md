# Миграция

Сверь пулы и эндпоинты через ресурс pools; регион SigV4 равен пулу. Адресация по умолчанию path-style. Переноси данные через локальный поток, presigned URL или multipart; серверная copy работает в пределах используемого S3-эндпоинта. Сверяй размеры и контрольные суммы до удаления источника. Не рассчитывай на перенос lifecycle, тегов, retention, encryption или replication через Selectel S3 API: их нет в таблице совместимости. Класс целевого бакета выбирает владелец в панели.
