# Selectel S3 v1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Execute sequentially; external reviews use the specification's agy/grok wrappers.

**Goal:** Deliver the CLI, stdio MCP server, embedded skill and twelve acceptance criteria of v1.

**Architecture:** Provider data is embedded in `internal/provider`; configuration and safety mediate every operation. MCP and CLI share an SDK-backed core, analytics and install packages. Safety checks precede network and filesystem side effects.

**Tech Stack:** Go 1.27, AWS SDK v2, MCP go-sdk v1.8.0, Cobra, YAML v3, TOML v2, versitygw v1.8.0.

**Spec:** `docs/specs/v1-selectel.md` (binding design and execution order).

## Global Constraints

- Work in this disposable clone on `v1-selectel`; do not push or touch the live checkout.
- Preserve all protected files in section 6 and the already committed specification.
- Run builds and tests in Docker with the current uid; use the supplied Go cache.
- Module `github.com/stufently/selectel-s3-mcp-ai-cli`, `go 1.27`, version `0.1.0`.
- Dependency floors and Docker/action pins are the exact research table versions.
- Secrets never appear in argv, logs, MCP responses or installed client configurations.
- Inline data limit 262144; preview 65536; list page limit 1000.
- Gates precede all S3 requests; scopes apply to source, destination, lists and bucket operations; local MCP files use `os.Root`.
- Provider literals are confined to `internal/provider` and `cmd`; generic code derives env names and URI schemes from `Profile`.
- Cross-review and reporting follow sections 8–10, including the explicit stop conditions.

## Review Focus

- Partial bucket scope: bucket administration and broad listings must fail before HTTP.
- Missing destination and non-404 HEAD errors: only genuine absence permits writes.
- Escaping symlinks and concurrent directory replacement: `os.Root` confines IO.
- Malformed, stale or oversized request arguments: fail clearly without partial actions.
- Existing unmanaged client config: preserve unrelated bytes and never replace outside owned markers.
