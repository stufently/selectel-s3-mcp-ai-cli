# Очередь вех

1. `v1-selectel` — весь v1 одной вехой (решение владельца 10.10.2026). Статус: принята и слита в `main` 2026-10-10 (плюс `v1-fix1`…`v1-fix3`).
2. Вторая волна (API управления, оценка стоимости, HTTP-режим, async-задачи) — после приёмки v1.
3. Вынос общего кода в `s3-mcp-ai-cli-kit` — при старте второго провайдера.
4. После приёмки v1 — вынести рабочие спеки и следы внутренней кухни (`/home/deploy/...`,
   исполнители, ревью) из публичного репо в приватное место; в `docs/` оставить только
   пользовательское.
